> I once reply-all'd 'Agreed!' to HR's email firing me, then spent an hour drafting a follow-up apologising for agreeing to my own termination.

141 characters (limit 200, one line). Painful honesty first, then the laugh: the worst moment is not the firing, it is agreeing with it in front of everyone — and then apologising for the agreement.
